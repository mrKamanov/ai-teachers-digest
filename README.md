# Factum Daily Post

Ежедневный пост-историю о необычных местах планеты для канала [max.ru/channel_factum](https://max.ru/channel_factum).

**Как работает:**
1. Каждый день в 14:00 МСК Gemini сам выбирает **новое необычное место** для поста, зная список всех уже опубликованных (в `history.json`) — статичный `config/places.json` остаётся только как запасной вариант, если Gemini недоступен
2. Gemini пишет пост в стиле автора канала (эталон — `prompts/style_example.txt`, промпт — `prompts/story.txt`), история всех прошлых постов скармливается в промпт для исключения повторов
3. В том же вызове Gemini даёт англоязычные запросы для фото — по ним ищутся файлы напрямую через бесплатный Commons API (Викисклад); каждая картинка скачивается и проверяется Gemini как модератор («узнаваемо ли место? нет запрещённого контента?»). Подтверждённое фото загружается в MAX и прикрепляется к посту; если ни одно не прошло проверку — пост уходит без фото
4. Пост сохраняется в `posts/YYYY-MM-DD.md`, история пополняется
5. Пост публикуется в канал через MAX Bot API
6. Всё коммитится — активность в репозитории каждый день

**Секреты (Settings → Secrets → Actions):**
- `GEMINI_API_KEY` — ключ Google AI Studio
- `MAX_BOT_TOKEN` — токен бота из «MAX для бизнеса»
- `MAX_CHAT_ID` — ID канала (без секрета публикация пропускается, пост всё равно генерируется и коммитится)

**Запасной список мест:** `config/places.json` → массив `places` (используется, только если выбор через Gemini не удался).
